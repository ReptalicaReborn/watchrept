# WatchRept

A Wear OS (Jetpack Compose for Wear OS) rep counter app.

## Build & run
1. Open this folder in Android Studio (Koala or newer).
2. Create a Wear OS emulator or connect a watch via ADB.
3. Run the `app` configuration, or `gradle :app:installDebug`.

Requires JDK 17, minSdk 30 (Wear OS 3+).
